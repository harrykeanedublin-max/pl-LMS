Football-themed color scheme; add club crests

Theme: pitch-green header with a subtle grass-stripe texture, emerald
primary buttons/links throughout, gold "Admin" nav link, and a
trophy/gold highlight for the standings leader.

Crests: added a crestUrl field to Team, looked up automatically via
Wikipedia's public search + summary API (no scraping) whenever a team
is added, with a "Refresh crest" retry button per team in
/admin/teams. Backfilled all 20 currently-seeded teams. Crests show
next to team names in the pick form (with a live preview as you
select), the pick history table, and admin fixture rows, with an
initial-letter fallback when a crest isn't available.
